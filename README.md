## 🚀 Getting Started Locally

To clone and run this portfolio application locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/muhsin-ahamed/muhsin-ahamed-personal-portfolio.git
   cd muhsin-ahamed-personal-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
