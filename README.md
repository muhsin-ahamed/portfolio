# Muhsin Ahamed T - Personal Portfolio

A modern, premium personal portfolio website showcasing the work and expertise of Muhsin Ahamed T, a Lead Software Engineer and Flutter Expert.

![Portfolio Preview](assets/hero-preview.png) *(Note: Add a screenshot of your portfolio here!)*

## 🚀 Features

- **Responsive Design**: Optimized for all devices, from mobile to desktop.
- **Dynamic Animations**: Smooth scroll and reveal animations using Intersection Observer.
- **Tech Stack Showcase**: Interactive grid of technical skills and design tools.
- **Project Gallery**: Highlights of development and design projects.
- **Contact Form**: Integrated with Google Forms for seamless message delivery.
- **Success Modal**: Immediate feedback upon form submission.

## 🛠️ Built With

- **HTML5**: Semantic structure.
- **Vanilla CSS3**: Custom styles with a focus on modern aesthetics (glassmorphism, gradients).
- **JavaScript**: Core logic for animations and dynamic content rendering.
- **Lucide Icons**: Clean and consistent iconography.
- **Google Fonts**: Inter & Space Mono for a professional look.

## 📱 Professional Focus

- **Design**: Adobe Creative Suite (Photoshop, Illustrator, InDesign, Premiere Pro), CorelDRAW.

## 🚀 Deployment

This project is ready to be hosted on **GitHub Pages**, **Netlify**, or **Vercel**. 

To host on GitHub Pages:
1. Go to the repository settings.
2. Navigate to "Pages" in the sidebar.
3. Select the `main` branch and "root" folder.
4. Click Save.
